# Data and documentation licence

The code in this repository is under the MIT licence (`LICENSE`).

The map data this project publishes (roof faces, panel layouts, yield and
money figures, map tiles) and the documentation in `docs/` are under the
[Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/legalcode).
You may share and adapt them for any purpose, including commercially, as long
as you give credit.

The published data is built from LINZ data that is itself CC BY 4.0, so
anyone reusing it must credit both sources. Use this line, or one that says
the same:

> Rooftop solar estimates by Rewiring Aotearoa (CC BY 4.0), built from LINZ
> building outlines, LiDAR, aerial imagery, DEM and addresses
> (Toitū Te Whenua Land Information New Zealand, CC BY 4.0).

Some inputs are not ours to relicense and are not covered here:

- **Esri World Imagery**, the map photo below zoom 14, is shown from Esri's
  servers under Esri's terms of use. This repository does not redistribute it.
- **NIWA** SolarView and measured-radiation data calibrate the sunlight model.
  Raw NIWA data is not redistributed; figures derived from it are.
- **ERA5** (Copernicus, via Open-Meteo) is CC BY 4.0 and is credited the same
  way as LINZ.
- **QLDC District Plan zoning** is used to tell homes from businesses and is
  Queenstown Lakes District Council's.
