## The run (on the VM, in ~/solar-map)

1. `bash tests/run_all.sh`: the same result as on the laptop, on the VM's
   Python.
2. `.venv/bin/python tests/test_golden.py --record`, then look at the render
   of every golden whose count moved and record the reason in the commit
   (made on the laptop). Judge by the renders, not the counts.
3. `bash src/run_district_build.sh` rebuilds all regions (incremental, which
   is a full build this once). Watch the log for STAGE FAILED.
4. `.venv/bin/python src/invariants.py <region>` for each region.
5. `.venv/bin/python tools/cases.py check --render` re-measures every
   flagged roof and renders the ones that changed to
   `data/preview/cases.html`.
6. `.venv/bin/python tools/explain_obstructions.py 5370328 5371137 5372604`
   shows, for every obstruction on those roofs, which detector drew it and
   how far its returns sit off the face's plane.
7. `.venv/bin/python tools/predeploy_check.py`; then, from the LAPTOP,
   `tools/deploy_from_vm.sh`. Look at what it shows, then run
   `tools/deploy_from_vm.sh --push`.

## What is still open, and how to attack it with real data

- **Obstructions over clear roof.** Read `explain_obstructions` for each
  roof:
  - HEIGHT obstructions whose returns sit far off the plane but lie flat
    are a neighbouring face's slope: overreach. Check whether plane_seams
    fired; `plane_seams.STATS` counts roofs and moves.
  - COLOUR-only blobs sitting on the plane (median near 0 m) along a fold
    are shading, not objects. On the synthetic L roof there is one of
    8.8 m2. A flush skylight looks the same to the LiDAR, so a fix must
    use the blob's shape or its position on the fold, not its height.
  - Very large single obstructions (9 Marine Parade had one of 97 m2) are
    worth a look on their own: which detector, and what the returns
    show.
- **Missed vents (1 Ballarat St).** Small objects the height detector did
  not flag. Check the returns over the vents against
  `HEIGHT_RESIDUAL_THRESHOLD_M` and `HEIGHT_MIN_CLUSTER_POINTS` in
  `src/obstruction_detection.py`.
- **The rest of BACKLOG.md**, in particular: eaves, imagery alignment, and
  the PVGIS derate check (a yield-only rebuild, no LiDAR).

## Rules that have held up

- Hand-drawn markup always wins over fitted geometry.
- Never sync code to the VM mid-build (`sync_vm.sh` refuses; respect it).
- A fix is general, not per-building: no special cases by ID.
- Every change runs `bash tests/run_all.sh`. If the synthetic reference
  moves on purpose, `tests/synthetic/run.py --record`, with the reason in
  the commit.
- Judge by renders and against markup, not by aggregate counts.
